\caption{BeaconMind architecture as designed. Solid borders mark the components the simulated study used;
dotted borders mark components that are built but were not used in it (the car and the validator); dashed
borders and arrows mark the real-car path, the room simulator, the closed loop and the demonstration runtime,
which were in progress or planned when this draft was built. The language model owns the pose belief and the
beacon map, while deterministic single-timestep tools compute every geometric quantity; in closed loop a
validator below the model checks every move. Arrows show the designed data flow.}
